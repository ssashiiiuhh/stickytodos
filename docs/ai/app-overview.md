# StickyToDos

StickyToDos is a lightweight native macOS productivity app.

It combines:
- menu bar quick capture
- sticky-note visualization
- semantic search
- intelligent natural-language task parsing

Core philosophy:
- instant interaction
- minimal cognitive load
- native macOS feel
- keyboard-first workflows
- smooth animations
- low memory usage

Avoid:
- feature bloat
- enterprise complexity
- unnecessary settings
- heavy background tasks
- overengineering
